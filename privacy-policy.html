PRISMBURST privacy policy

This policy covers PRISMBURST — Brick Odyssey: the Android app (package com.hamzaxali.prismburst) and the web game at hamzaxali.github.io/prismburst-brick-odyssey. It describes what the game actually collects.

Last updated: 22 October 2026.

Short version

  • You can play as a guest. Guest play sends nothing to a server.
  • If you choose to sign in, your email address, display name and game save are stored so your progress syncs.
  • No advertising SDK, no analytics, no tracking, no selling of data.
  • The “ads” in the game are demo ads drawn by the game itself. They only promote PRISMBURST and never contact an ad network.
  • Coins and shop items are in-game only. There are no real-money purchases.
  • You can delete your account at any time: delete-account.html.

Who is responsible

The game is made by the developer behind the GitHub account HamzaXali (repository HamzaXali/prismburst-brick-odyssey). Cloud accounts are stored in the developer's Supabase project.

The game does not ask for contacts, location, photos, camera, microphone or device identifiers for advertising. The Android app only uses the Internet permission. The game has no analytics or crash-reporting SDK and no third-party advertising SDK.

Supabase (the hosting provider) processes sign-in requests and may keep standard server logs such as IP addresses for security, under its own policy. GitHub Pages, which serves the web game, may also keep standard access logs. Google sign-in is handled by Google under Google's policy.

How data is protected

Data is sent over HTTPS. The game only contains Supabase's publishable key. Row level security lets each signed-in player read and change only their own row. Secret keys are never shipped in the app.

Sharing

Data is not sold or shared with third parties for advertising or any other purpose. It is processed only by the service providers named above to run the game.

Retention

Device data stays until you use Settings → Reset progress, clear the app or site data, or uninstall the app. Account data (email, provider id, display name, cloud save) stays until you delete the account. Deletion removes it from the live database straight away. Routine backups held by Supabase, if any, are overwritten on their normal schedule and are not used to restore deleted accounts.

How to delete your data

  • Account and cloud save: in the game open Settings → Delete account, sign in, type DELETE and confirm. Or use the web page delete-account.html.
  • This device: after deleting the account the game asks whether to also clear this device's progress. You can also use Settings → Reset progress at any time, or uninstall the app.

Children

The game is intended for players aged 13 and over and is not directed at children. It does not knowingly collect personal information from children under 13. Guest play needs no personal information. If you believe a child has created an account, use the deletion page or contact the developer.

Changes

If this policy changes, the updated version is published at this same address with a new date.
