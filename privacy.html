PRISMBURST privacy policy

This policy covers the game at PRISMBURST — Brick Odyssey. It describes what the game actually stores. There are no ads and no analytics.

Last updated: 27 October 2026.

Who is responsible

The game is published by the owner of the GitHub repository HamzaXali/prismburst-brick-odyssey. Cloud saves, if you turn them on, are stored in that owner's Supabase project.

Data on this device

The game always saves progress in this browser under the key prismburst.save.v1. That includes unlocked levels, scores, stars, coins, owned and equipped skins, settings (sound, vibration, screen shake), daily reward and mission state, and lifetime stats. A timestamped backup may also be stored on this device before a cloud copy replaces that save. This data stays on the phone until you use Settings → Reset progress or clear the site's data in the browser.

A display name is stored separately under prismburst.profile.v1. Guest play creates a name such as PrismPlayer1234 on this device. Reset progress does not remove that name. Clearing the site's data does.

Data if you create an account

Account sign-in is optional. Guest play does not create an account and does not send a save to a server. If you sign in, the game sends the following to the owner's Supabase project:

  • Your email address, if the provider supplies one.
  • The sign-in provider (email, Google, or Facebook) and the account id that provider assigns.
  • Your game save, a save version, and the time this device last changed it.
  • The display name you save for the account. The game does not use your email address as that name. Google may suggest the name on the Google account; nothing is stored until you confirm it.

The game does not ask for your contacts, location, photos, or microphone. It does not sell data. The publishable Supabase key in the game can only access the row that belongs to the signed-in account. The secret key never ships in the game.

How long it is kept

The device copy lasts until you reset it or clear site data. The display name on the device lasts until you clear site data. The cloud copy of the save, and the account display name, last until the account is deleted. Deleting the user in Supabase also deletes that user's cloud save and display name.

How to delete your data

On this phone: open the game, go to Settings, choose Reset progress, and confirm. That clears the copy stored on this device. It does not delete a cloud account.

Cloud account and cloud save: sign out in the game (Account → Log out). Then ask the project owner, the GitHub account that hosts this game, to delete your user in the Supabase dashboard under Authentication → Users. Deleting that user deletes the cloud save. There is no separate advertising profile to remove.

This site is a static page, so it cannot run an automatic server callback. The steps above are the data-deletion instructions.

Children

The game is not directed at children under 13, and it does not knowingly collect their personal information.
